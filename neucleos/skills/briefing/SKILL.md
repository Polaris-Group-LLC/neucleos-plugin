The person has requested Neucleos work. Follow the opening skill first if the workspace is not already open in this conversation.

Write the briefing the person asked for with this command as a canvas in Neucleos. If they did not say what it is about, ask in one short question first.

1. Read the guide with topics words and canvases, and clients when the brief concerns a client, account, prospect, deal or discovery work.
2. world_list, then find the existing brief and work before creating a duplicate. For discovery, work_resume, claim_find and source_search within the work; read the cited units and keep any new findings as claims. Preserve the person's own notes and state unread material and unresolved questions.
3. object_read an existing Page, otherwise canvas_create makes one (an object). Then object_create its pieces and place them with object_update: a Text with the summary first, a Text per point, a Table bound to a Dataset for live facts, Images from Media where useful. Discovery statements cite claims as [^c12]. canvas_write and canvas_read are the legacy block-format path for pages made before the object model; they refuse an object-backed Page. Sharing must also allow access to the supporting work and sources. Make a separate sanitized page for a wider audience.
4. artifact_open puts it in front of them; if their cockpit is not open, use cockpit_link and the opening skill to open it in the current host, then verify it and say where it opened.
5. Tell them what it covers. It is private to them: share it only if they ask.
