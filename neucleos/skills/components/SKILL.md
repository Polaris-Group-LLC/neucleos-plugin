# components

Components are compiled in development and registered for reuse. Discover existing pieces with object_catalog and component_search; configure their data in production. Use object_catalog to discover the reusable pieces installed in this environment. Use object_list with its continuation cursor to find saved work, then object_read before changing it. New workspace Pages, Desktops and Sites use object_create with their config, placements and bindings. Create Text and other registered pieces from data, then place the same object where needed. Live selections follow later revisions; pinned selections name one revision. object_update requires the revision read before editing. Use object_open to leave the result saved and usable. Each surface uses the World's brand. Never compile UI code in production; if a needed piece is missing, identify that gap. Published websites still use site_create/site_write/site_publish; workspace Sites do not provision a hostname. Existing legacy content remains readable and editable through its original tools; object_migration_plan reports which saved content can be migrated without loss.
