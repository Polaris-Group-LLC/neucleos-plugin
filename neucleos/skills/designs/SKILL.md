# designs

Designs are editable creative artifacts, distinct from reusable Widgets and exported Files. First call design_capabilities, then design_template with a tool: shape-magic, background-studio, texture-lab, sound-lab, center-stage or blender. design_catalog searches available presets, effects, sound recipes or geometry; parameters:true returns texture settings and defaults. design_create accepts tool and an optional complete template document; without tool it makes a mark. All new designs are private. design_read returns the saved document, revision, selected IDs, renderer version, history and this person's exports.
For shape-magic use the layer operations documented by the template: update/add/remove/reorder/artboard. Other tools use {op:"set",path:"camera.zoom",value:1.2}, or e.g. {op:"set",path:"layers.0.params.shift",value:120}. Read the current document first. Replace a whole layers/devices/objects array to add, remove or reorder; keep unique IDs. Always send expectedRevision and a unique key with design_change. Repeat the exact key and input only to retry. Stale writes are refused. design_undo restores the previous document as a new revision. A selected item's ID is context, not authority; match it to the latest document before changing it.
Texture sources and device artwork accept immutable {artifactId,revision} references to visible Files in the same World. Images and video may total 5 MB, at most 4 MB each; 3D model inputs are embedded GLB files. Never put external URLs or credentials into a document. The person and Cleo share the same editor state. Mark coordinates are pixels; scene positions are world units and rotations are degrees. Shape Magic currently supports four primitives and flat/metal fill. Background Studio admits five compact shaders plus 63 qualified source-catalog backgrounds. Use design_catalog, then design_template with the preset ID to get its complete settings. Presets that failed qualification remain unavailable. Texture Lab admits 77 effects; Sound Lab has 200 recipes. The 3D editor supports parametric primitives and imported GLB geometry; arbitrary modeling work can also run through execution_submit with Blender and then be added as a File.
Place a live Design with @@design <title or artifactId> / @@end in a Canvas. On Desktop use @@design <placement name>, use: <title or artifactId>, @@end. Add revision: N to pin it. Sharing a host never grants access to a private source; share only when asked.
design_export takes an explicit saved revision, format and unique key. Graphics support PNG/JPEG/WebP and bounded MP4/WebM/GIF animation; marks support PNG and flat SVG; sounds support WAV/MP3/OGG; 3D additionally supports GLB and editable .blend. Video is limited to 1024 pixels per side and 180 frames; MP4 needs even dimensions. Texture video retains source audio when audio is enabled; GIF has no audio. Poll design_read.exports, then design_download. Exports become private Files after authorization is rechecked. Cloud execution must be enabled in the World; GPUs are not enabled by these tools.
