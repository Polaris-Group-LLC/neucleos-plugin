# agents

An agent is a model with a role that people use where you place it: a concierge on a desktop over a dataset, an Ask on a canvas, an app page's helper. Make one with agent_create: a name, its tier (Neucleos Low for quick, light answers, Medium for everyday work, High for hard problems, XHigh for the most capable; each has its price, which the person sees on the Usage page), its instructions (who it is, what it knows, how it answers), the datasets it reads (and writes, when it should change them), the sketchboards it reads and draws on (name them in writes too; it answers with a diagram there), its memory (none, each viewer's own, or shared), and web search when it should answer with today's facts: name web_search in its tools (Neucleos Medium, High or XHigh only); it searches up to five times an answer, each search charged at the tier's search price (on the Usage page), and its answer comes with the pages it used, which agent_ask returns as sources. Place it with a component that has an agent input, such as Neucleos's Chat ("@@component Concierge", "use: Chat", "agent: agent <name>"). On a Neucleos Image tier (Low, Medium, High) an agent makes a picture from what it is asked, its instructions its style (no datasets, tools or memory). For a picture you place yourself (a canvas's hero picture from its first paragraph), make one in the person's World with agent_create and ask it with agent_ask: the picture is media in that World, private, to show on a canvas ("@@media <its name>", the name agent_ask gives). For people to make pictures themselves, place Neucleos's Picture component with Neucleos's own picture agent, which every World can use there ("use: Picture", "agent: agent Neucleos Picture", "prompt: …"); what it makes is shared as the place it was made is. On Neucleos Video an agent makes a short video as a job: it names the most it may cost when it starts, a World that cannot afford that is refused, and it is charged for the seconds the video runs; it lands in the World's media when done, minutes later. Everything it runs is charged to the World of the artifact it runs in, from what the provider reports it used; a World out of credits refuses runs. An agent is private until shared like anything else: a shared desktop's agent must be shared too, or members cannot use it. Try it with agent_ask (on the person's credits) before placing it. agent_write changes it as a new version; agent_read shows its settings, price, versions and what it has cost this month. app_agent gives an app's page an agent (window.claude.use("ai") and window.claude.complete(prompt) in the page). On a schedule: agent_schedule asks an agent to do a task at set times ("every Monday at 8, have the market agent update Competitors"): every day, every weekday, on days of the week (0 Sunday to 6 Saturday) or a day of the month, at an hour and minute in the person's time zone (their cockpit's, unless you name one). It runs as the person who made it, on the World's credits, admitted like any run; text agents only. Each run keeps what it changed; the person is told in Activity when it runs, fails or pauses. It pauses itself after three failures in a row, and 60 days after it was last confirmed. agent_schedules lists them with their latest runs; schedule_change runs one now, pauses, resumes (or confirms), or removes it. Say the time back in words, with its time zone, and what each run may cost (the agent's tier).
